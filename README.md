# GridfirE
Prosta strzelanka online w rzucie izometrycznym

## Opis
Projekt na zajęcia z Agorytmów i gier decyzyjnych. 
Gra polega na zdobyciu największej ilości punktów poprzez eliminację przeciwników przed upłynięciem czasu.
Istnieje możliwość ustawienia wielkości drużyn, kupowania lepszego uzbrojenia, amunicji i życia za uzbierane pieniądze. Gra posiada 2 poziomy oraz kreator postaci.
Użyte pluginy:
- [RpcAwait](https://github.com/dominiks/rpc-await)
[LocalStorage](https://github.com/Desssuka/LocalStoragePlugin)
